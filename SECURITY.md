# Security policy

FYNX Wallet is an owner-only testnet implementation with a public waitlist. It is not independently audited or approved for public real-funds use.

Report security issues privately to **fynxteam5@gmail.com**. Include the affected URL, steps, impact and a minimal reproduction. Do not include private keys, recovery words, account passwords, tokens or customer data. Do not use a public GitHub issue for a sensitive vulnerability. No bounty or response-time commitment has been established.

The security review and threat model are in `security_best_practices_report.md` and `FYNX-Wallet-threat-model.md`. Operational response steps are in `docs/OPERATIONS.md`. Public launch gates are in `docs/LAUNCH-READINESS.md`.
